# אתר לסוכנת נדל״ן

React + TypeScript (Vite) לאתר עצמו, ושרת Node.js/Express שמנהל את הנכסים, התמונות והפניות.

## מה יש באתר

- **דף בית**: קרוסלה של נכסים נבחרים, רשימת נכסים עם סינון (מכירה / השכרה / עיר), אודות, טופס יצירת קשר.
- **עמוד נכס**: גלריית תמונות עם תמונות ממוזערות, החלקה בנייד ותצוגת מסך מלא, פרטי הנכס, כפתורי חיוג ו-וואטסאפ, טופס לתיאום ביקור.
- **רשתות חברתיות**: כפתורים בתחתית ובאזור צור קשר, וכפתור וואטסאפ צף.
- **איזור ניהול** (`/admin`, מוגן בסיסמה): הוספה, עריכה ומחיקה של נכסים, העלאת תמונות וסידור שלהן, סימון "נמכר", הסתרה (טיוטה), בחירת נכסים לקרוסלה, ותיבת פניות מהאתר.

## הרצה מקומית

דרוש Node.js 20 ומעלה.

```bash
npm install
cp .env.example .env      # ולערוך: ADMIN_PASSWORD ו-JWT_SECRET
npm run dev
```

- האתר: http://localhost:5173
- ניהול: http://localhost:5173/admin

בהרצה הראשונה נוצר `data/db.json` עם 4 נכסים לדוגמה (בלי תמונות). אפשר למחוק אותם מאיזור הניהול.

## התאמה לסוכנת

כל הפרטים האישיים נמצאים בקובץ אחד: `src/config.ts` – שם, טלפון, וואטסאפ, אימייל, כתובת, טקסט אודות וקישורי הרשתות החברתיות. רשת עם קישור ריק לא תוצג.
תמונה של הסוכנת: שמים קובץ בתיקיית `public` (למשל `public/agent.jpg`) וכותבים `agentPhoto: '/agent.jpg'`.
צבעים וגופנים: המשתנים בראש `src/styles.css`.
כותרת ותיאור לגוגל: `index.html`.

## העלאה לאוויר ב-Vercel

בענן הנכסים והפניות נשמרים ב-**Supabase** (טבלה) והתמונות ב-**Supabase Storage** (לשניהם יש מסלול חינמי). מקומית הכל נשמר בקבצים בתיקיית `data`, כמו קודם. הקוד בוחר לבד לפי משתני הסביבה.

1. מעלים את הקוד למאגר ב-GitHub.
2. ב-[vercel.com](https://vercel.com): **Add New → Project**, בוחרים את המאגר ולוחצים Deploy (ההגדרות נקראות מ-`vercel.json`).
3. בפרויקט, לשונית **Storage**: **Supabase** (מה-Marketplace, יש מסלול חינמי), ומחברים לפרויקט. המפתחות נוספים אוטומטית. אחר כך מריצים את `supabase/schema.sql` ב-Supabase → SQL Editor (פעם אחת).
4. **Settings → Environment Variables**: מוסיפים `ADMIN_PASSWORD`, `JWT_SECRET` (מחרוזת אקראית ארוכה, **חובה** בענן) ואם רוצים גם את הגדרות ה-SMTP.
5. **Deployments → Redeploy** כדי שההגדרות ייכנסו לתוקף.

בפריסה הראשונה נוצרים 4 נכסים לדוגמה. כדי להעביר לענן את הנכסים, הפניות והתמונות שכבר יש במחשב:

```bash
npx vercel link
npx vercel env pull .env.local
npm run migrate
```

האתר יכול לרוץ גם על שרת רגיל (`npm run build && npm start`), ואז הנתונים נשמרים בתיקיית `DATA_DIR` שחייבת להיות על דיסק קבוע.

## מבנה

```
api/index.ts     נקודת הכניסה ב-Vercel
server/          שרת Express
  app.ts         כל נקודות ה-API
  index.ts       הרצה מקומית / שרת רגיל
  auth.ts        התחברות (סיסמה + עוגיית JWT), הגבלת ניסיונות
  db.ts          אחסון: Supabase בענן, קובץ JSON מקומית
  validate.ts    בדיקת נתונים שמגיעים מהדפדפן
  mailer.ts      מייל על פנייה חדשה (אופציונלי, SMTP)
shared/types.ts  טיפוסים משותפים לשרת ולאתר
src/
  config.ts      פרטי הסוכנת
  pages/         דף בית, עמוד נכס, כניסה, ניהול, טופס נכס
  components/    קרוסלה, גלריה, טופס יצירת קשר, כרטיס נכס ועוד
```

## הערות

- **אחסון**: כל הנתונים הם מסמך JSON אחד (ב-Supabase או בקובץ), וזה מתאים לאתר של סוכנת אחת (מאות נכסים). כל הגישה לנתונים מרוכזת ב-`server/db.ts`.
- **תמונות**: עד 10MB לתמונה, והן נשמרות כמו שהן. כדאי להעלות תמונות מוקטנות (רוחב 2000 פיקסלים מספיק). אפשר להוסיף כיווץ אוטומטי עם `sharp` ב-`server/app.ts`.
- **אבטחה**: סיסמה אחת לסוכנת, נשמרת רק ב-`.env`. יש הגבלה של 8 ניסיונות התחברות ל-15 דקות, ושדה מלכודת נגד בוטים בטופס יצירת הקשר.
- **מיילים**: אם מגדירים SMTP ב-`.env` (למשל Gmail עם App Password), כל פנייה חדשה נשלחת גם למייל של הסוכנת. בלי זה, הפניות מופיעות רק באיזור הניהול.
